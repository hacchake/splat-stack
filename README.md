# Splat Stack

実物を 3D Gaussian Splatting（3DGS）でスキャンしたデータ（.ply / .splat）を読み込み、
水平に輪切りしてスプライトスタッキング用のスライス画像に変換し、ブラウザでくるくる回せるビューアです。
「実物スキャン → ドット絵の2.5Dオブジェクトに変身」する様子を、そのままX用の動画に書き出せます。

> Claude Code（Opus 5.5）を使用して制作

| フェーズ | 内容 | 状態 |
|---|---|---|
| 1 | 読み込み・プレビュー・上方向合わせ・クロップ・ゴミ取り | ✅ |
| 2 | スライスへの焼き込み・書き出し（PNGシート／連番ZIP） | ✅ |
| 3 | スプライトスタッキングのビューア | ✅ |
| 3.5 | ガウシアン・スタック描画モード・3分割比較 | ✅ |
| 4 | 左右比較・変身演出・録画（MP4）・プリセット | ✅ |

## 起動方法（Windows）

### 必要なもの
- **Node.js**（バージョン20以上）… https://nodejs.org/ja から「LTS」をダウンロードしてインストール
- **Google Chrome** または **Microsoft Edge**（最新版）。動画の書き出しはこの2つで確認しています

### 起動
1. このフォルダ（`splat-stack`）を開く
2. **`起動.bat` をダブルクリック**
   - 初回だけ、必要な部品のダウンロードに1〜2分かかります
   - 自動でブラウザが開き、Splat Stack の画面が出ます
   - 開かないときは、ブラウザで http://localhost:5173 を開いてください
3. 終わるときは、黒いウィンドウ（コマンドプロンプト）を閉じます

コマンドで起動したい場合は、このフォルダでPowerShellを開いて次を実行します。

```powershell
npm install
```

```powershell
npm run dev -- --open
```

## いちばん短い使い方：X投稿用の動画を作る

1. 画面に `.ply` をドラッグ＆ドロップ（試すだけなら右の「**木**」）
2. **2.** 「地面をクリックして水平合わせ」→ 画面の地面をクリック
3. **4.** 「近くの仲間がこれ未満なら除去」を3〜5くらいに（浮いたゴミが消えます）
4. **3.** 「自動で囲む」→「地面より上だけ残す」
5. **9.** プリセット（ゲームボーイ風・ファミコン風など）を1つ押す（自動で焼き込みまで行います）
6. **9.** 録画の「大きさ」「構成」「長さ」を選んで **「録画して保存」**
7. ダウンロードフォルダに MP4 ができるので、そのままXに投稿

## 画面の見方

画面上のタブで表示を切り替えます（「焼き込む」の後に全部使えます）。どれも**同じカメラ**なので、切り替えても同じ角度・同じ大きさです。

| タブ | 内容 |
|---|---|
| 元の3DGS | 読み込んだデータそのもの（下ごしらえはこの画面で） |
| ガウシアン | ガウシアン・スタック（ピクセル化せず、ガウシアンのまま輪切りにして重ねたもの） |
| ドット絵スタック | 焼き込んだスライス画像を重ねたもの（ソフトモードなら「ソフトスタック」） |
| 左右比較 | 左に元の3DGS、右にスタック。同じ角度で一緒に回る |
| 3分割 | 元の3DGS／ガウシアン・スタック／ドット絵スタックを並べて、FPS・数・メモリを比べる |
| 変身 | 元の3DGSが下から1枚ずつ輪切りになって、ドット絵に変わっていく演出 |

マウス操作：左ドラッグ＝回転（上下で俯角）、右ドラッグ（または Shift＋左ドラッグ）＝移動（3DGS表示のみ）、ホイール＝ズーム

## パネルの各項目

### 1. 読み込み
- `.ply` か `.splat` を**ドラッグ＆ドロップ**、または「ファイルを選ぶ」
- 「色付き立方体」「木」：テスト用データ（わざと斜めに傾けて、周りにゴミや薄いモヤを混ぜてあります）
- 「負荷テスト100万個」：重いデータでも動くかの確認用

### 2. 上方向を合わせる
- **おすすめ：「地面をクリックして水平合わせ」** → 地面（または机の面）をクリック。周りのガウシアンから平面を推定して、自動で水平にします
- 細かい調整は X/Y/Z 軸の回転スライダー。上下が逆さまのときは「上下反転」
- 水色の矢印が「上方向」。輪切りはこの矢印に垂直な向きで行われます

### 3. クロップボックス（対象物だけ残す）
- 「自動で囲む」：残っている部分をおおよそ囲みます
- 「地面より上だけ残す」：水平合わせでクリックした地面を消します
- X/Y/Z の下限・上限スライダーで、オレンジの箱を詰めます。箱の外は消えます

### 4. ゴミ取りフィルタ
- **不透明度の下限**：これより薄いガウシアン（モヤ）を消します
- **近くの仲間がこれ未満なら除去**：ぽつんと浮いたゴミ（フローター）を消します。「孤立判定の距離」は「近く」とみなす範囲
- 「除去される部分を赤で表示」をオンにすると、消える部分が赤く見えて調整しやすくなります

### 5. スライスに焼き込む
- **枚数**（8〜128）と**解像度**（16〜256px）。3D表示の水色の横線が輪切りの位置です
- 焼き込む範囲は「いま表示されているガウシアン」がちょうど収まる大きさに自動で決まります
- 出力モード
  - **ソフト**：ガウシアンのぼかしを残した、なめらかな見た目
  - **ドット絵**：最近傍で縮小 → 全層共通のパレットに減色 → アルファを2値化
    - **色数**（4〜32）と**パレット**：自動（メディアンカット）／ゲームボーイ4階調／ファミコンの色に寄せる／PICO-8の16色に寄せる
    - **アルファのしきい値**：低くすると輪郭が太く、高くすると細く
    - **輪の内側を埋める（中空対策）**：スキャンデータは表面にしかガウシアンがないので輪切りが「輪」になります。その内側を近い色で埋めます（ふつうはオン）
    - **輪郭線（シルエットの外側）**：重ねた後の外側だけに線を付けます（表示と動画用）
    - **スライス画像にも輪郭線を付ける（書き出し用）**：各スライス画像の周りに1pxの線。重ねると側面が線の色になるので、ふつうはオフ
- モード・色数・パレット・しきい値・輪郭線は、焼き直さなくてもすぐ反映されます。
  回転・クロップ・フィルタ・枚数・解像度を変えたら、もう一度「焼き込む」を押してください
- 「スライス一覧を開く」で全スライスを確認できます

### 6. 書き出す
- **スプライトシート（PNG）**：全層を縦（または横）に並べた1枚の画像
- **連番PNG（ZIP）**：`slice_000.png`… と、層の厚みなどを書いた `info.json`
- 「層の順番」はふつう「下の層が先頭」（Godot・GameMakerなどのスプライトスタッキングの一般的な形）。「拡大」で1ドットを2倍・4倍に

### 7. スタック表示
- **自動回転**／**回転の速さ**（マイナスで逆回り）／**高さの倍率**（1 = 実物どおりの比率）
- **厚み補間**：各スライスを何回かずらして重ね描きして、層のすき間を埋めます（「自動」がおすすめ）
- **高さによる明るさの差**：下の層ほど暗くして立体感を出します
- **影の濃さ／光の向き／光の高さ**：地面に落ちる影

### 8. ガウシアン・スタック
- 各ガウシアンを所属するスライスの高さに置き、上下の厚みを潰した「平たい楕円」として、層の下から順に描きます。
  層の順番がそのまま奥行きの順番なので、**ガウシアン単位の並べ替えをしません**
- **上方向の厚み**：0（平ら）だと層のすき間が縞模様に見えることがあります。少し上げるとなめらかにつながります

### 9. デモ・録画（X投稿用）
- **プリセット**：背景色・解像度・色数・パレット・輪郭線をまとめて変えます（ゲームボーイ風／ファミコン風／16色／PICO-8風／なめらか）。データがあれば自動で焼き直します
- **左右比較の右側**：ドット絵スタックかガウシアン・スタックかを選びます
- **変身を再生**：約3秒かけて、下から1枚ずつドット絵に変わります。もう一度押すと元に戻ります。「進み具合」スライダーで手動でも動かせます
- **録画**
  - 大きさ：1080×1080（正方形）／1080×1920（縦長）
  - 構成：**変身ループ**（3DGSで回る → 変身 → ドット絵で回る → 逆変身 → 3DGSに戻る）／**比較**（横長なら左右、縦長なら上下に並べて回る）
  - 長さ：10〜20秒。どの構成も**ちょうど1回転して最初と同じ絵で終わる**ので、Xでくり返し再生されても継ぎ目が見えません
  - 「動画に文字を入れる」：タイトルと「Claude Code（Opus 5.5）を使用して制作」を動画に入れます
  - 「デモを再生」で、録画せずに中身を確認できます
- 書き出しは**1コマずつ**（60fps、H.264のMP4）行うので、パソコンが遅くてもカクつかず、長さもぴったりです。
  そのかわり実際の長さより時間がかかることがあります（進捗バーに残り時間が出ます）
- WebCodecs に対応していないブラウザでは、画面をそのまま録画する方式（WebMになることがあります）に切り替わります。
  WebM しかできなかった場合は、Xに投稿する前に MP4 に変換してください（例：HandBrake などの変換ソフト）

## Scaniverse から .ply を書き出す手順

1. Scaniverse（iPhone / Android）でスキャンするときに、処理モードで **「Splat」** を選んで処理します
2. スキャン一覧から作品を開き、**共有（Share）** ボタン → **「Export Model」**
3. 形式に **「PLY」** を選んで書き出し、AirDrop・メール・Googleドライブなどでパソコンへ送ります
4. パソコンで受け取った `.ply` を Splat Stack にドラッグ＆ドロップ

※ アプリのバージョンによってボタン名が少し違うことがあります。
※ `.spz` 形式は未対応です。PLYを選んでください。

### そのほかのアプリ
- **Polycam**：Gaussian Splat で撮影 → Export → PLY
- **Luma AI**：作品ページの「Download」→ Gaussian Splat（.ply）
- **SuperSplat**（ブラウザの編集ツール）：「圧縮PLY」は未対応なので、書き出し時に**圧縮なしのPLY**を選んでください。`.splat` 形式でも読み込めます

### スキャンのコツ
- 物体の周りを一周、高さを変えて2〜3周撮ると、輪切りにしたときに穴が少なくなります
- 机や床の上に置いて撮ると、「地面をクリックして水平合わせ」がうまく効きます

## 対応している形式
- `.ply`：3DGS標準形式（x, y, z, scale_0〜2, rot_0〜3, opacity, f_dc_0〜2。高次の球面調和係数は無視）。
  binary（little/big endian）と ascii の両方。色だけの点群PLY（red/green/blue）も読めます
- `.splat`：antimatter15 形式（1個32バイト）

## 技術メモ
- Vite + TypeScript + WebGL2。外部ライブラリは MP4 を作るための `mp4-muxer` だけです
- ファイルの解析・奥行きの並べ替え・孤立判定は Web Worker（別スレッド）、焼き込みはGPU（WebGL2）で行い、進捗バーを出します
- スライスは並び順＝奥行き順なので、スタック表示（ドット絵・ガウシアンとも）ではガウシアン単位の並べ替えをしていません
- 変身演出では、まだ変わっていない部分を「厚みを残したガウシアン・スタック」で、変わった部分をドット絵で、同じ正射影で描いて境目をそろえています
- 動画は WebCodecs の VideoEncoder（H.264）で1コマずつ書き出し、`mp4-muxer` で MP4 にまとめています
